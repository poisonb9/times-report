Times Report

Personal desktop tool for publishing short video clips to a single TikTok account.

About this application

Times Report is a personal, single-user desktop tool. It selects highlight segments from long-form video, renders them as short vertical clips with burned-in captions, and publishes the finished files to the operator's own TikTok account using TikTok's Content Posting API.

There is exactly one operator: the person who built and runs it on their own computer. The tool does not accept sign-ups, does not act on behalf of other users, and does not store or share TikTok account data with any third party.

Privacy Policy

Effective date: 26 July 2026

1. Data collected

The app stores, locally on the operator's own computer only, the OAuth access token and refresh token issued by TikTok after authorization, plus the minimal account identifier needed to publish content (open_id). No other personal data is collected from TikTok or from any viewer of the published videos.

The app also reads back, through the Display API (video.list), the aggregate public statistics of the operator's own published videos — view, like, comment and share counts. These numbers are written to a local file on the operator's computer and used only to decide which clips to produce next. No metrics belonging to any other account are requested, stored or displayed.

2. Data storage

Tokens are written to a local file on the operator's computer. They are never transmitted anywhere except directly to TikTok's own API endpoints (open.tiktokapis.com) to refresh a session or publish a video.

3. Data sharing

No data is sold, rented, or shared with any third party, advertiser, or analytics service. There are no other users of this application besides its single operator.

4. Data deletion

The operator can revoke access at any time from TikTok's account settings, or delete the local token file to remove all locally stored credentials immediately.

5. Contact

Questions about this policy can be directed to the developer account associated with this application in the TikTok for Developers portal.
